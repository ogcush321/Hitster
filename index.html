This is a classic mobile web problem. When a smartphone screen turns off, the phone's operating system cuts the browser's internet connection to save battery life. Because Firebase instantly sees the connection drop, it assumes the player left and triggers the `onDisconnect` command, wiping them from the game. To fix this, we can use a special built-in Firebase feature called `.info/connected`. It acts like a heartbeat monitor. If a phone goes to sleep and drops off the database, this monitor waits for the phone to wake back up. The exact millisecond the phone wakes up and reconnects to the internet, the game will automatically quietly inject the player's name back into the active list without them having to refresh the page.
